# Interview Management System

A web-based application designed to schedule, manage, and organize job interviews efficiently.

## About the Project

The Interview Management System helps users manage their interview schedules in one place. Users can add, view, update, delete, search, and filter interview details through a simple and user-friendly interface.

## Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Node.js

**Database**
- MySQL

## Features

- User Registration and Login
- User Dashboard
- Add New Interviews
- View Scheduled Interviews
- Update Interview Details
- Delete Interviews
- Search Interviews
- Filter Interviews by Status
- Settings Management
- Forgot Password and Reset Password Pages

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Mudassir1825/Interview-Management-System.git
```

2. Navigate to the project directory:

```bash
cd Interview-Management-System
```

3. Install the required dependencies using npm in the relevant project directories.

4. Configure your MySQL database and backend environment variables.

5. Start the backend using the start script defined in its package.json.

6. Open the frontend in your browser or use your configured local development server.
